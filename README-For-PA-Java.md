# ☕ Estruturas de Repetição `for` — Programação e Algoritmos

## 📋 Sobre o projeto

Este repositório reúne **exercícios acadêmicos desenvolvidos em Java** para praticar a estrutura de repetição `for` na disciplina de **Programação e Algoritmos (PA)**.

As atividades abordam contagens crescentes e decrescentes, seleção de números por condições, cálculos matemáticos e leitura de valores digitados pelo usuário. Os exercícios estão organizados em quatro grupos, permitindo acompanhar a aplicação progressiva dos conceitos.

## 🎯 Finalidade

O projeto tem como finalidade desenvolver o raciocínio lógico e a familiaridade com a sintaxe de Java, especialmente no uso de laços de repetição para executar instruções um número definido de vezes.

Entre os conceitos praticados estão:

- Inicialização, condição e atualização de variáveis em um `for`;
- Contagens em ordem crescente e decrescente;
- Estruturas condicionais `if` e operador de resto `%`;
- Acumuladores e cálculos com números inteiros;
- Entrada de dados pelo teclado com `Scanner`;
- Exibição de resultados no console.

## ⚙️ Exercícios desenvolvidos

### 1. `ForParai` — Contagens básicas

| Arquivo | O que faz |
| --- | --- |
| `UmateDez.java` | Exibe os números de 1 a 10. |
| `DezaoUm.java` | Exibe os números de 10 a 1. |
| `VinteateZero.java` | Exibe os números de 0 a 20, em ordem crescente. |
| `ZeroateVinte.java` | Exibe os números de 20 a 0, em ordem decrescente. |

> Os nomes dos dois últimos arquivos não correspondem à direção da contagem implementada. As descrições acima refletem o comportamento do código.

## 🛠️ Tecnologias e recursos utilizados

- **Java:** linguagem de programação utilizada em todos os exercícios.
- **`for`:** estrutura de repetição principal das atividades.
- **`if`:** estrutura condicional utilizada para filtrar ou comparar valores.
- **`Scanner`:** classe da biblioteca padrão do Java utilizada para ler dados digitados pelo usuário.
- **Console:** ambiente de entrada e saída dos programas.

## ▶️ Como executar

É necessário ter um **JDK (Java Development Kit)** instalado. Os arquivos podem ser executados em uma IDE Java ou pelo terminal, respeitando a declaração `package` de cada classe.

Por exemplo, para executar `UmateDez.java` a partir da pasta que contém o diretório `forparai`:

```bash
javac forparai/UmateDez.java
java forparai.UmateDez
```

Os outros exercícios podem ser executados da mesma forma, ajustando o nome do pacote e da classe. Em uma IDE, basta importar o projeto e executar o método `main` do exercício desejado.
