# ☕ Exercícios com FOR em Java — Programação e Algoritmos

## 📋 Sobre o Projeto

Este repositório reúne uma série de exercícios desenvolvidos em **Java**, como parte das atividades acadêmicas da disciplina de **Programação e Algoritmos (PA)**.

O projeto tem como finalidade praticar a utilização da estrutura de repetição `for`, explorando sua aplicação em contagens, operações matemáticas, verificações condicionais e processamento de dados informados pelo usuário.

As atividades estão organizadas em quatro grupos, permitindo acompanhar a aplicação dos conceitos de lógica de programação em exercícios com diferentes níveis de complexidade.

## 🎯 Objetivos

- Compreender o funcionamento da estrutura de repetição `for`.
- Desenvolver algoritmos utilizando contadores e acumuladores.
- Realizar contagens crescentes e decrescentes.
- Aplicar operações matemáticas dentro de estruturas de repetição.
- Utilizar condições com `if` para selecionar determinados valores.
- Trabalhar com entrada de dados utilizando a classe `Scanner`.
- Desenvolver o raciocínio lógico e a resolução de problemas em Java.

## ⚙️ Exercícios Desenvolvidos

### 📁 ForParai — Estruturas Básicas

Este primeiro grupo apresenta exercícios introdutórios para compreender o funcionamento do laço `for`, utilizando contagens e alterações no valor de uma variável.

- **UmateDez.java:** realiza uma contagem crescente de 1 até 10.
- **DezaoUm.java:** apresenta uma contagem decrescente de 10 até 1.
- **VinteateZero.java:** realiza uma contagem crescente de 0 até 20.
- **ZeroateVinte.java:** apresenta uma contagem decrescente de 20 até 0.

### 📁 ForParai2 — Condições e Seleção de Números

O segundo grupo combina a estrutura de repetição `for` com verificações condicionais, permitindo selecionar números de acordo com determinadas características.

- **Impares99.java:** apresenta os números ímpares de 1 até 99.
- **Pares100.java:** identifica e exibe os números pares de 0 até 100.
- **Multiplos5.java:** apresenta os múltiplos de 5 entre 0 e 100.
- **Maiores25.java:** exibe os números maiores que 25 e menores que 50.

### 📁 ForParai3 — Operações Matemáticas

O terceiro grupo utiliza estruturas de repetição para realizar cálculos matemáticos, trabalhando com variáveis acumuladoras e multiplicações.

- **FatoriaLate10.java:** calcula o produto dos números de 1 até 10, equivalente ao fatorial de 10.
- **SomaPar.java:** realiza a soma acumulada dos números de 1 até 100, exibindo os resultados parciais.
- **SomaPar1ate100.java:** calcula a soma dos números pares entre 1 e 100.
- **Tabuada.java:** solicita um número inteiro ao usuário e apresenta sua tabuada de multiplicação de 1 até 10.

### 📁 ForParai4 — Entrada e Processamento de Dados

O quarto grupo apresenta exercícios que utilizam a classe `Scanner` para receber valores informados pelo usuário e processá-los por meio de estruturas de repetição.

- **Ler10eSoma.java:** solicita dez números inteiros e calcula a soma dos valores digitados.
- **Ler10MaiorNum.java:** recebe dez números e identifica o maior valor informado.
- **LerNumero1.java:** solicita um número inteiro e apresenta uma contagem crescente de 1 até o valor digitado.
- **LerPar.java:** recebe dez números inteiros e informa quantos deles são pares.

## 🛠️ Tecnologias e Recursos Utilizados

- **Java:** linguagem de programação utilizada no desenvolvimento dos exercícios.
- **Estrutura `for`:** responsável pelo controle das repetições.
- **Estrutura `if`:** utilizada para verificar condições durante a execução.
- **Classe `Scanner`:** utilizada para a leitura de dados informados pelo usuário.
- **Operadores aritméticos e relacionais:** empregados em cálculos, comparações e verificações.
- **Variáveis contadoras e acumuladoras:** utilizadas para controlar repetições e armazenar resultados.

## ▶️ Como Executar

Para executar os exercícios, é necessário possuir o **Java Development Kit (JDK)** instalado e utilizar uma IDE compatível com Java.

1. Clone ou baixe este repositório.
2. Abra o projeto em uma IDE Java.
3. Localize o exercício desejado.
4. Execute a classe que contém o método `main`.
5. Observe os resultados no console e, quando solicitado, informe os valores necessários.

Cada exercício possui sua própria classe principal e pode ser executado individualmente.
