# Currículo CSS 💻

Projeto de desenvolvimento web criado para apresentar currículos em um site, com páginas estruturadas em **HTML** e estilizadas com **CSS**.

## 🌐 Acesse o projeto

O site está publicado na Vercel: **[curriculo-css.vercel.app](https://curriculo-css.vercel.app/)**.

## 🎯 Objetivo

Praticar os fundamentos de desenvolvimento front-end, especialmente a organização de conteúdo com HTML, a criação de estilos com CSS e a navegação entre páginas. O resultado é um pequeno portfólio online que permite acessar os currículos apresentados no projeto.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura e conteúdo das páginas.
- **CSS3:** cores, fontes, espaçamentos e apresentação visual.
- **Vercel:** publicação do site na internet.

## 📁 Estrutura do projeto

```text
curriculoCSS/
├── index.html      # Página inicial do site
├── html/           # Páginas HTML dos currículos
├── css/            # Arquivos de estilo
└── imagens/        # Imagens utilizadas no projeto
```

## 🚀 Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/MelissaCrepaldi/curriculoCSS.git
   ```

2. Abra a pasta `curriculoCSS` no editor de sua preferência.
3. Abra o arquivo `index.html` no navegador para visualizar o site localmente.

Também é possível acessar a versão publicada pelo link acima, sem instalar nada.
